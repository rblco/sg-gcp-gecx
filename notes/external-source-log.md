## Vendor primary documentation - network, audit, and safety

| Configure VPC Service Controls for CX Agent Studio | https://docs.cloud.google.com/gemini-enterprise-cx/cx-agent-studio/vpc-service-controls | Both `ces.googleapis.com` and `contactcenterinsights.googleapis.com` must be added to the restricted services list. Seven documented in-perimeter breakages: tools and callbacks cannot reach arbitrary HTTP endpoints; Cloud Storage audio outside the perimeter fails; BigQuery export outside the perimeter fails; "Sensitive Data Protection redaction templates outside the perimeter cause failures in redacting conversation contents"; "OpenAPI tools cannot reference authentication keys using secrets that are outside the perimeter"; "Datastore tools that specify a data store outside the perimeter fail to execute"; cross-perimeter agent calls and import/export to external buckets fail. Authorized views cannot edit or import conversation data, train topic models, or create scorecards. |
